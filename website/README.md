# Web pública de descargas

La web muestra las cuatro plataformas previstas de Brotes de Olivo Music.
Solo se habilita el botón de una plataforma cuando `downloads/manifest.json` indica `available: true`.

La web no contiene versiones ni URLs de descarga codificadas en HTML: lee el manifiesto público, por lo que una nueva publicación no requiere modificar la página.
